Analytics

Up 
get /analytics/topsofthetops
Obtener los mejores de los mejores (getTopsoftheTops)
Recupera información sobre los juegos más populares y los streamers más destacados en ellos.

Query parameters

since (optional)
Query Parameter — Tiempo en segundos para actualizar los datos desde la última consulta. Si no se proporciona, se utiliza un valor por defecto de 600 segundos.

Return type

array[TopGame]

Example data

Content-Type: application/json
[ {
  "game_name" : "game_name",
  "most_viewed_views" : 1,
  "user_name" : "user_name",
  "most_viewed_created_at" : "2000-01-23T04:56:07.000+00:00",
  "most_viewed_title" : "most_viewed_title",
  "total_views" : 6,
  "total_videos" : 0,
  "most_viewed_duration" : "most_viewed_duration",
  "game_id" : "game_id"
}, {
  "game_name" : "game_name",
  "most_viewed_views" : 1,
  "user_name" : "user_name",
  "most_viewed_created_at" : "2000-01-23T04:56:07.000+00:00",
  "most_viewed_title" : "most_viewed_title",
  "total_views" : 6,
  "total_videos" : 0,
  "most_viewed_duration" : "most_viewed_duration",
  "game_id" : "game_id"
} ]

Produces

This API call produces the following media types according to the Accept request header; the media type will be conveyed by the Content-Type response header.
  • application/json

Responses

200

Datos obtenidos correctamente.

400

Parámetro 'since' inválido. ErrorResponse

Example data

Content-Type: invalid_since
{"error":"Bad Request. Invalid or missing parameters."}

404

No se encontraron datos disponibles. ErrorResponse

Example data

Content-Type: no_data
{"error":"Not Found. No data available."}

500

Error interno del servidor. ErrorResponse

Example data

Content-Type: internal_server_error
{"error":"Internal Server Error. Please try again later."}

Autenticacin

Up 
post /token
Generar token de acceso (generateToken)
Genera un token de acceso para autenticación en la API basado en el email y API key del usuario.

Consumes

This API call consumes the following media types via the Content-Type request header:
  • application/json

Request body

body GenerateTokenRequest (required)
Body Parameter —

Return type

TokenResponse

Example data

Content-Type: application/json
{
  "token" : "token"
}

Produces

This API call produces the following media types according to the Accept request header; the media type will be conveyed by the Content-Type response header.
  • application/json

Responses

200

Token generado exitosamente. TokenResponse

400

Datos inválidos para generación de token. ErrorResponse

Example data

Content-Type: email_missing
{"error":"The email is mandatory"}

Example data

Content-Type: api_key_missing
{"error":"The api_key is mandatory"}

Example data

Content-Type: email_invalid
{"error":"The email must be a valid email address"}

401

No autorizado. API key inválida o email no registrado. ErrorResponse

Example data

Content-Type: unauthorized
{"error":"Unauthorized. API access token is invalid."}

500

Error interno del servidor. ErrorResponse

Example data

Content-Type: internal_server_error
{"error":"Internal server error."}

  "id" : "id",
  "login" : "login",
  "display_name" : "display_name",
  "type" : "type",
  "view_count" : 0
}
